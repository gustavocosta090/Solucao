Criar Conta de Usuário

Atenção: Anote a senha e passe para a pessoa. Se ela entrar com a senha padrão 123456, o sistema oferecerá a troca logo após o login.

Ferramentas

Cria no SharePoint as pastas dos clientes que ainda não possuem (Obras e Clientes / Ordens de Serviço / Fotos / Relatórios de Vistoria / Arquivos de Backups + subpastas por equipe). Clientes e pastas já existentes são ignorados automaticamente. 



    

    

      Atribui N.OS às agendas antigas que estão sem número (ignora viagens). Cada agenda recebe um número novo e as OSs vinculadas recebem o mesmo número. Agendas que já têm número não são tocadas.
